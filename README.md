# AIRES — landing page

Static site, no build step: `index.html`, `style.css`, `script.js`, `assets/`.

- Run locally: `python3 -m http.server 8765` then open http://127.0.0.1:8765/
- The “Contact a member” button opens the visitor’s mail app to `contact@airesresearch.org`.
- Team links go to each member’s public profile (LinkedIn, portfolio, ResearchGate, or Medium).
- Logo files in `assets/` are the earlier wordmark. The page header uses an inline mark so it matches the current layout.
